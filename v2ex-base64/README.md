# V2EX Base64 自动解析

独立的 userscript 脚本，打开 V2EX 主题页面后自动解析正文和回复中的 Base64 内容，也支持动态新增的回复和已有文本的更新。

## 安装

安装 Tampermonkey 或 Violentmonkey 等脚本管理器，新建脚本，粘贴 `main.user.js` 的内容并保存，然后打开或刷新 V2EX 主题页面。

脚本运行于 `v2ex.com` 及其子域名下的 `/t/*` 页面，无需外部依赖、构建步骤或特权脚本 API。

## 功能

- 扫描 `#Main` 内的 `.topic_content` 和 `.reply_content`。
- 保留 Base64 原文，在一个空格后显示解析结果，不添加括号。
- 解析结果参考 V2EX Polish 的样式：13px 字号、橙色高亮、无下划线及复制光标。内置浅色和 V2EX 夜间模式配色，优先使用页面中已有的 Polish 主题变量。
- 点击高亮结果即可复制，也可通过键盘聚焦后按 Enter 或空格键复制。悬停或键盘聚焦时，结果上方显示提示；复制成功后显示 `✅ Copied!`，持续 1 秒；失败显示 `Copy failed`，持续 2 秒。反馈期间移开鼠标仍可见，连续点击会重置提示时间。
- HTTP 页面或浏览器权限限制可能导致复制失败，失败信息会显示在浮动提示和浏览器控制台中。此时可选中解析结果手动复制。
- 监听新增内容和文本更新，不会重复解析自身生成的结果。
- 兼容 V2EX Polish 重建或克隆回复内容（例如隐藏 @ 用户名、热门回复展示）：复制事件统一绑定在 `#Main` 上，结果节点被重建后仍可复制。
- 跳过链接、图片属性、脚本、样式、表单控件和可编辑区域。解析出的 HTML 仅作为纯文本显示。
- 没有可解析内容时不弹出通知。

## 识别限制

候选文本必须使用标准 Base64 字符集，长度大于 8 且为 4 的倍数，末尾填充合法，并且能够解码为 UTF-8。无效候选会保留原样。普通文本偶尔也可能满足这些条件，因此保留编码原文供核对。

不支持 URL 安全格式的 Base64、短字符串、缺少填充后不满足长度要求的字符串、跨 DOM 节点的字符串或递归解码。脚本监听已有的 `#Main` 容器；替换整个容器或仅修改 CSS 类名不会触发重新识别，遇到此类情况请刷新页面。
